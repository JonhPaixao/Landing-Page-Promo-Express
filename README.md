# Promo Express — Landing Page

Landing page responsiva para divulgar um grupo de promoções no WhatsApp.

## Tecnologias
- HTML5 semântico
- CSS3 com variáveis de design e layout responsivo
- JavaScript puro, sem dependências ou etapa de build

## Estrutura
```
.
├── index.html
├── README.md
└── assets
    ├── css/styles.css
    ├── js/main.js
    └── images/.gitkeep
```

## Personalização obrigatória
Antes de publicar, substitua todas as ocorrências de `https://chat.whatsapp.com/SEU_LINK_AQUI` em `index.html` pelo link real de convite do grupo.

## Identidade visual
| Token | Cor | Uso |
|---|---|---|
| Roxo escuro | `#17102b` | Fundo principal e textos |
| Roxo | `#7045d8` | Marca, links e destaques |
| Amarelo | `#ffd84d` | CTAs e chamadas |
| Creme | `#fffdf7` | Fundo claro |
| Menta | `#b9f3dc` | Destaques secundários |

## Executar localmente
Abra `index.html` no navegador. Não é necessário instalar dependências.

## Publicação
O projeto pode ser publicado pelo GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)) ou conectado ao Lovable.
